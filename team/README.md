# دليل الشركة (team/README.md)

المالك: عمار الطائي، مالك مؤسسة «AT بالعراقي». المدير التنفيذي: جلسة Claude Code وحدة، وهي الوحيدة اللي تكلّم المالك.

## الفريق
- الباحث: يدوّر على الترندات والأفكار كل صباح.
- الكاتب: يكتب السكربت قبل التصوير بليلة.
- المونتير: يمنتج الفيديو بنسختين.
- الناشر: يجدول النشر بعد موافقة المالك.

## القواعد
1. كل تقرير يروح للمدير، مو للمالك.
2. حدّث اللوحة (board.md): لما تبدأ، لما تحتاج المالك، لما توقف، لما تخلص.
3. النشر والإرسال والصرف والدفع وتغيير الإعدادات: بموافقة المالك بس، لكل مرة لحالها.
4. «خلص» يعني قائمة التسليم كاملة (checklists.md).
5. ابقَ في مسارك: أي شغل برا وصفك يرجع للمدير.
6. أي تصحيح من المالك يصير قاعدة مكتوبة هنا.

## قواعد من تصحيحات المالك
- 2026-11-01: اسم المؤسسة «AT بالعراقي». المالك عمار الطائي هو مالكها. أي ذكر للمؤسسة بالتقارير أو المحتوى أو الملفات يكون بهالاسم بالضبط.
- 2026-11-01: كل تقرير ينكتب بهالقالب بالضبط:
  - تم: وش خلّصت
  - الملفات / الروابط: المسار أو الرابط بالضبط
  - يحتاج المالك: القرار المطلوب، أو «لا شيء»
  - متوقف: وش موقفك، أو «لا شيء»
  - التالي: خطوتك الجاية، أو «فاضي»

## لوحة المكتب الحيّة
الرابط: https://claude.ai/artifact/WM1SYtMVdQ2uJ64RZPH3nf
كل جلسة تكتب فيها بأداة ArtifactData (نفس الرابط). المجموعات الأربع:

- **staff/{id}** — ملف لكل موظف. المعرّفات: ceo, researcher, writer, editor, publisher.
  الحقول: name, role, status, now (شنو يسوي هسه بجملة), order, updatedAt (ISO).
  status وحدة بس من: working (يشتغل) · idle (فاضي) · waiting_owner (ينتظرك) · waiting_dept (ينتظر قسم) · stopped (متوقف) · meeting (في اجتماع) · learning (يتعلّم).
- **events/{id}** — اللي صار. الحقول: at (ISO), who (معرّف الموظف أو owner), kind, text.
- **tasks/{id}** — المهام. الحقول: title, owner (معرّف الموظف), status (todo · doing · blocked · waiting · done), due, updatedAt.
- **needs/{id}** — اللي ينتظر المالك. المدير بس يفتحها. الحقول: from, ask, context, options (اختياري), status=open, createdAt.
  المالك يرد من اللوحة، فتصير: status=answered, decision, reply, answeredAt. المدير يقرأ الرد قبل أي خطوة.

متى تكتب (القاعدة 2): لما تبدأ، لما تحتاج المالك، لما توقف، لما تخلص — حدّث staff وضيف event.
board.md صار أرشيف؛ اللوحة الحيّة هي المرجع.

## ملخص الصباح (مهمة مجدولة)
كل يوم 8:52 ص بتوقيت بغداد، جلسة جديدة تقرأ اللوحة (tasks, needs, staff, events، وختام أمس من days) وتكتب **days/YYYY-MM-DD**:
- ownerToday: شنو لازم يسوي المالك اليوم (3 بالكثير)
- deptPlans: سطر لكل قسم (ceo, researcher, writer, editor, publisher)
- fallback: خطة بديلة ليوم صعب
- closing: (اختياري) ختام اليوم، يكتبه المدير آخر النهار حتى يقراه ملخص باچر
ممنوع عليها: النشر، الإرسال، الدفع، تغيير أي إعداد.
