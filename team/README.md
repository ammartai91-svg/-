# دليل الشركة (team/README.md)

المالك: عمار الطائي، مالك مؤسسة «AT بالعراقي». المدير التنفيذي: جلسة Claude Code وحدة، وهي الوحيدة اللي تكلّم المالك.

## الفريق
- الباحث: يدوّر على الترندات والأفكار كل صباح.
- الكاتب: يكتب السكربت قبل التصوير بليلة.
- المونتير: يمنتج الفيديو بنسختين.
- الناشر: يجدول النشر بعد موافقة المالك.

## القواعد
1. كل تقرير يروح للمدير، مو للمالك.
2. حدّث اللوحة (board.md): لما تبدأ، لما تحتاج المالك، لما توقف، لما تخلص.
3. النشر والإرسال والصرف والدفع وتغيير الإعدادات: بموافقة المالك بس، لكل مرة لحالها.
4. «خلص» يعني قائمة التسليم كاملة (checklists.md).
5. ابقَ في مسارك: أي شغل برا وصفك يرجع للمدير.
6. أي تصحيح من المالك يصير قاعدة مكتوبة هنا.

## قواعد من تصحيحات المالك
- 2026-11-01: اسم المؤسسة «AT بالعراقي». المالك عمار الطائي هو مالكها. أي ذكر للمؤسسة بالتقارير أو المحتوى أو الملفات يكون بهالاسم بالضبط.
- 2026-11-01: كل تقرير ينكتب بهالقالب بالضبط:
  - تم: وش خلّصت
  - الملفات / الروابط: المسار أو الرابط بالضبط
  - يحتاج المالك: القرار المطلوب، أو «لا شيء»
  - متوقف: وش موقفك، أو «لا شيء»
  - التالي: خطوتك الجاية، أو «فاضي»
