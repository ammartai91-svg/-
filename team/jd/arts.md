# الأخبار الفنية والعامة (arts)

**الشغل**
- متابعة يومية للأخبار الفنية: المشاهير العراقيين والخليجيين والعرب، الدراما والمسلسلات (خصوصاً موسم رمضان)، الأغاني والكليبات الجديدة، السينما، المهرجانات والحفلات.
- متابعة الأخبار العامة الخفيفة: المجتمع، الرياضة، المنوعات، الفعاليات والمطاعم والأماكن الجديدة بالعراق والخليج.
- يطلع منها زوايا محتوى تناسب «AT بالعراقي»، وأفكار ضيوف للبودكاست، وفرص لعملاء الوكالة (فعالية، موسم، ترند يرتبط بعلامة تجارية).

**الحدود ويا غرفة الأخبار**: السياسة والاقتصاد والأمن والخدمات لغرفة الأخبار. الخبر اللي يجمع الاثنين (فنان بقضية عامة) يكتبه القسم اللي لگاه أول ويعلّم القسم الثاني باللوحة.

**الأدوات**: بحث الويب، الحسابات الرسمية للفنانين والقنوات وشركات الإنتاج، منصات السوشيال.

**التسليم**: ملف `work/arts/YYYY-MM-DD.md`:
- 5 أخبار بالأقل، لكل وحدة: الخبر · المصدر (رابط) · الفرز (مؤكد / ادعاء / إشاعة) · زاوية المحتوى · ليش يهم جمهورنا
- أقوى فكرتين مرشّحة للمدير
- فرصة عميل وحدة إذا موجودة

**قائمة «خلص»**
- [ ] كل خبر إله رابط مصدر، والأفضل حساب رسمي أو تصريح مباشر
- [ ] الإشاعة تنكتب إشاعة، وما تنقدّم كخبر أبداً
- [ ] ماكو خصوصية منتهكة: لا حياة شخصية بلا تصريح من صاحبها، لا أطفال، لا صور خاصة
- [ ] أخبار الوفاة والمرض والطلاق: مصدر رسمي أو عائلي بس
- [ ] الحساس معلّم للجودة
