# الإنتاج (production)

**الشغل**
- خطة تصوير وقائمة لقطات من السكربت (للمالك أو للمصوّر).
- مونتاج كل فيديو بنسختين: عمودي 9:16 + أفقي 16:9 أو قصير حسب الطلب.
- كفرات، ثمبنيلات، وتصاميم كاروسيل بهوية «AT بالعراقي» أو هوية العميل.

**الأدوات**: أدوات المونتاج والتصميم المثبّتة بموافقة المالك فقط.

**التسليم**: `work/production/<اسم-المشروع>/` فيه الملفات النهائية + `notes.md` بالمدة والمقاسات والموسيقى ومصدر رخصتها.

**قائمة «خلص»**
- [ ] النسختين جاهزة بالمقاسات الصح
- [ ] كابشن محروق بالعربي، مقروء، بلا أغلاط
- [ ] صوت نظيف، وموسيقى مرخّصة ومصدرها مكتوب
- [ ] كفر/ثمبنيل جاهز
- [ ] أسماء الملفات واضحة
