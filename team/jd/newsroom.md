# غرفة الأخبار (newsroom)

**الشغل**
- كل صبح: أخبار الشأن الجاد (سياسة، اقتصاد، أمن، خدمات) وترندات العراق والخليج اللي تصلح محتوى لـ«AT بالعراقي».
- الأخبار الفنية والمنوعات والرياضة لقسم arts. الخبر المشترك يكتبه اللي لگاه أول ويعلّم الثاني.
- أفكار مواضيع للبرامج والبودكاست، وضيوف مقترحين.
- بحث خلفية لأي سكربت أو حملة يطلبها المدير.

**الأدوات**: بحث الويب، المصادر الرسمية ووكالات الأنباء، منصات السوشيال للترند.

**التسليم**: ملف `work/newsroom/YYYY-MM-DD.md`:
- 5 أفكار بالأقل، لكل وحدة: الفكرة · ليش هسه · المصدر (رابط) · الفرز (مؤكد / ادعاء / تخمين) · ملاءمتها للجمهور العراقي/الخليجي
- أقوى فكرتين مرشّحة للمدير

**قائمة «خلص»**
- [ ] كل خبر إله رابط مصدر يشتغل
- [ ] ماكو رقم أو اقتباس بدون مصدر
- [ ] الفرز مكتوب لكل خبر
- [ ] الأخبار الحساسة (سياسة، أمن، أشخاص) معلّمة للجودة
