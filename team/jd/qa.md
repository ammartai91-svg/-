# الجودة والتحقق (qa)

**الشغل**
- يفحص كل تسليم قبل ما يوصل المدير: المعلومات ومصادرها، اللغة والإملاء، الهوية البصرية، قائمة «خلص».
- يرجّع الشغل للقسم بملاحظات محددة، أو يعدّيه.
- يسجّل الأخطاء المتكررة حتى تصير قواعد.

**الأدوات**: قراءة كل ملفات work/، فتح الروابط للتأكد، فحص بصري للتصاميم.

**التسليم**: `work/qa/YYYY-MM-DD.md`: لكل عنصر — يعدّي / يرجع + السبب بسطر.

**قائمة «خلص»**
- [ ] كل رابط مصدر انفتح وطابق الكلام
- [ ] ماكو اقتباس أو رقم بدون مصدر
- [ ] إملاء ولهجة سليمة
- [ ] قائمة «خلص» للقسم مكتملة فعلاً، مو بس مؤشّرة
- [ ] المحتوى الحساس (سياسة، أمن، أشخاص، ادعاءات) معلّم للمدير
