# قوائم التسليم — «خلص» ما ينقال إلا لما كل بند مؤشَّر

## الباحث (كل صباح)
- [ ] 5 أفكار على الأقل، كل وحدة بسطر: الفكرة + ليش هسه + المصدر (رابط)
- [ ] فرز: مؤكَّد / ادعاء / تخمين — ولا رقم ولا اقتباس بدون مصدر
- [ ] ملاءمة للجمهور العراقي/الخليجي مذكورة
- [ ] أقوى فكرتين مرشّحة للمدير

## الكاتب (قبل التصوير بليلة)
- [ ] هوك أول 3 ثواني (نسختين)
- [ ] سكربت بالدقيقة/الثانية: حوار، زوايا كاميرا، نص على الشاشة، مؤثرات، انتقالات
- [ ] Payoff واضح + نهاية تنحفظ + CTA
- [ ] لهجة عراقية طبيعية (إلا إذا انطلب غيرها)
- [ ] كل معلومة بالسكربت إلها مصدر من الباحث

## المونتير
- [ ] نسختين: عمودي 9:16 (ريلز/تيك توك) + نسخة ثانية حسب الطلب (أفقي 16:9 أو قصيرة)
- [ ] كابشن محروق بالعربي، خط مقروء، بلا أخطاء إملائية
- [ ] صوت نظيف + موسيقى مرخّصة
- [ ] كفر/ثمبنيل
- [ ] الملفات بمكانها واسمها واضح

## الناشر
- [ ] كابشن + هاشتاغات + وقت النشر المقترح
- [ ] موافقة المالك مكتوبة لهالمنشور بالذات (رقم المنشور + التاريخ)
- [ ] بعد النشر: الرابط مسجّل باللوحة
