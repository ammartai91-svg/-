# قوائم «خلص» لكل مرحلة

«خلص» ما ينگال إلا لما كل بند مؤشّر **ومتحقق منه**. التفاصيل الكاملة لكل قسم بـ jd/.

## 1. الفكرة (newsroom)
- [ ] 5 أفكار بالأقل، كل وحدة بمصدر يشتغل
- [ ] فرز: مؤكد / ادعاء / تخمين
- [ ] ليش هسه + ملاءمتها للجمهور
- [ ] أقوى فكرتين مرشّحة

## 1ب. الأخبار الفنية والعامة (arts)
- [ ] 5 أخبار بالأقل، كل وحدة بمصدر (حساب رسمي إذا ممكن)
- [ ] فرز: مؤكد / ادعاء / إشاعة، والإشاعة ما تنقدّم كخبر
- [ ] ماكو انتهاك خصوصية
- [ ] زاوية محتوى + أقوى فكرتين

## 2. السكربت (creative)
- [ ] هوكين لأول 3 ثواني
- [ ] سكربت بالثانية: حوار، كاميرا، نص شاشة، مؤثرات، انتقالات
- [ ] Payoff + نهاية + CTA
- [ ] لهجة عراقية طبيعية
- [ ] كل معلومة إلها مصدر

## 3. الإنتاج (production)
- [ ] نسختين بالمقاسات الصح
- [ ] كابشن محروق بلا أغلاط
- [ ] صوت نظيف وموسيقى مرخّصة (المصدر مكتوب)
- [ ] كفر/ثمبنيل

## 4. الجودة (qa)
- [ ] المصادر انفتحت وتطابق
- [ ] الإملاء واللهجة والهوية سليمة
- [ ] قائمة المرحلة السابقة مكتملة فعلاً
- [ ] الحساس معلّم للمدير

## 5. الموافقة (ceo ← المالك)
- [ ] need باللوحة بسؤال واحد واضح ورابط التسليم
- [ ] رد المالك مقروء ومسجّل قبل أي خطوة

## 6. النشر (publishing)
- [ ] موافقة المالك على **هالمنشور بالذات**
- [ ] الحزمة: كابشن، هاشتاغ، وقت (12 ساعة)، منصات
- [ ] الرابط بعد النشر مسجّل كحدث

## 7. شغل العملاء (sales)
- [ ] العرض: مشكلة، حل، تسليمات، جدول، سعر ومنطقه، KPIs
- [ ] أسعار واقعية للسوق العراقي
- [ ] ماكو وعود بأرقام ما نضمنها
- [ ] الإرسال للعميل = need للمالك
