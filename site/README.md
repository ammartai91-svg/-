# موقع at بالعراقي

- `index.html` — الموقع كامل بملف واحد. افتحه بأي متصفح (دبل كلك).
- `logo.png` — اللوغو الرسمي (يظهر بالهيدر وأيقونة التبويب). لازم يبقى بنفس فولدر `index.html`.
- `logo.svg` — نسخة فيكتور قديمة مرسومة، احتياط.

## وين تعدّل
افتح `index.html` بمحرر نصوص (VS Code مثلاً) وابحث عن:
- `const SITE` — الاسم، الروابط، الإيميل، إظهار الشريط التجريبي والإعلانات، أرقام الحساب.
- `const ARTICLES` — الأخبار. كل خبر سطر واحد (id, cat, t, time, hero, breaking, img, sum, body, author).
- `const CATS` — الأقسام وألوانها.
- `const ABOUT` — صفحة من نحن.

الخط Cairo يُحمّل من Google Fonts، فيحتاج إنترنت حتى يظهر صح.
