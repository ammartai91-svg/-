# ريل نصائح الدكتورة

ريل عمودي (1080×1920، 30fps). الدكتورة قاعدة بغرفة بيضة على يسار الكادر، والنقاط الأربعة تطلع يمينها بستايل موشن قريب من الريفرنس: عنوان متوهج، رقم كبير مفرّغ، إطار سداسي، شريط بحث، قوس زجاجي، فلاش انعكاس، وختام بموجة تركواز. وفوقها تعديل لوني سينمائي.

## التعديل: كلشي من ملف واحد

افتح `src/content.ts`:

| شتريد تغيّر | وين |
| --- | --- |
| نص نقطة، رقمها، أيقونتها | `points` |
| وقت ظهور النقطة (بالثواني) | `start` و `duration` بكل نقطة |
| تضيف نقطة خامسة | انسخ بلوك نقطة والصقه بعد الرابعة، وغيّر `start` |
| تحذف نقطة | امسح البلوك مالها |
| شريط البحث | `search` (احذفه إذا ما تريده) |
| فلاش الانعكاس | `flash: true` |
| زوم الكاميرا | `zoom` (1 عريض، 1.14 قريب) |
| الافتتاحية والختام | `hook` و `outro` |
| الألوان | `colors` |
| مكان الدكتورة وحجمها | `doctor.x` و `doctor.y` و `doctor.height` |
| الموسيقى والمؤثرات | `audio` (تحط ملف موسيقى بمجلد `public/music` وتكتب اسمه) |
| الكلر كريدنگ | `grade` (0 يطفي أي طبقة) |

الأيقونات المتوفرة: `calendar` و `apple` و `pill` و `alert` و `heart` و `stethoscope`.

المؤثرات الصوتية تنحط **تلقائياً** حسب التوقيتات، فإذا غيّرت وقت نقطة يمشي صوتها وياها.

## التشغيل

```bash
npm install
npm run studio          # معاينة حيّة وتعديل بالمتصفح
npm run render          # الفيديو النهائي -> out/doctor-reel.mp4
npm run render:overlay  # الموشن بس بخلفية شفافة (ProRes 4444) لأفتر / بريمير
```

## إضافة فيديو الدكتورة

```bash
pip install rembg onnxruntime
python3 tools/prepare_doctor.py "path/to/doctor.mov"
```

يطلع ملف `public/video/doctor-cutout.webm` (الدكتورة بدون خلفية). بعدها بـ `content.ts` اكتب:
`doctor.src: 'video/doctor-cutout.webm'`

## الصوت

`tools/make_sounds.py` يولّد الموسيقى والمؤثرات محلياً، فهي حرّة وما عليها حقوق.
إذا تريد تراك مرخّص، بدّل `public/music/bed.wav` بنفس الاسم أو غيّر المسار بـ `content.ts`.
